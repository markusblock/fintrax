# Local store backup strategy

Fintrax uses Eclipse Store's continuous backup as a lightweight, continuously updated mirror and creates one full point-in-time backup on every app launch, retaining the 30 newest completed copies. The mirror is not a historical snapshot series; Eclipse Store exposes no lightweight point-in-time snapshot API, while full backups copy the whole store and pause storage operations. Full backups run off the UI thread and are published only after a successful copy so a failed backup cannot replace a known-good one. The default destination is `~/.fintrax/backups`; users can configure another location in Settings, with changes applied after restart because Eclipse Store requires the continuous-backup target during store startup. If backup setup fails, Fintrax asks the user to choose another folder and restart or exit. The default is on the same disk for convenience, and recovery guidance recommends another disk/location for disk-failure protection.
